# widgets/

- `neumorphic.dart` — the GRIVIO design system: `Neumorphic` surfaces
  (raised/inset/flat), `NeumorphicButton`, `GrivioLogo`, progress ring,
  badges and the theme selector.
- `ui_kit.dart` — decorative layer: `AmbientBackground`, `StaggeredIn`
  entrance animation, `GrivioWordmark`, `PulseRing`, `LoadingDots`, `ErrorPill`.
